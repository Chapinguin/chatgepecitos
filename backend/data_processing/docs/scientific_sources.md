# Scientific Data Sources

## NASA Planetary Analog Explorer

### Moon
- Agency: NASA
- Mission: Lunar Reconnaissance Orbiter (LRO)
- Instrument: Diviner
- Archive: NASA Planetary Data System (PDS)
- Source: https://pds-geosciences.wustl.edu/missions/lro/diviner.htm
- Products: EDR, RDR, GDR
- Status: Official source identified; measurements not yet imported.

### Mars
- Status: Scientific measurements not yet imported.
- Requirement: Record mission, instrument, product, coordinates and units before accepting observations.

### Earth
- Dataset: out/analogues.geojson
- Content: 5175 geographical candidate patches.
- Status: Candidate geometries and similarity scores generated by the team's processing pipeline.
- Limitation: Similarity scores are not independently verified environmental measurements.

## Data integrity

- Synthetic data must remain identified as synthetic.
- Missing measurements must not be replaced with invented values.
- Diviner RDR uses -9999 for some missing brightness-temperature values.
- Scientific observations require traceable product identifiers.
- Original measurements must be preserved during normalization.
- Processing must work offline with locally available datasets.

## Current limitations

The project includes synthetic reference records and terrestrial candidate regions.
Official NASA lunar and Martian measurements have not yet been imported.
The data-processing module is suitable for prototype integration, not for claiming validated planetary scientific results.
